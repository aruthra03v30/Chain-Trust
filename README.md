# CHAIN TRUST – Blockchain-Based Freelance Contract & Payment Escrow System

## Abstract

CHAIN TRUST is a blockchain-based freelance contract and payment escrow system designed to improve trust, transparency, and security between clients and freelancers. In traditional freelancing, issues such as payment delays, payment disputes, lack of transparency, and breach of agreements can create difficulties for both parties.

The proposed system uses blockchain technology and smart contracts to manage freelance agreements and payments securely. Clients can create projects, specify contract details, and deposit payments into an escrow smart contract. The payment remains secured until the agreed work is completed and approved, after which it can be released to the freelancer. The system also supports dispute handling to help address disagreements between clients and freelancers.

CHAIN TRUST integrates Ethereum smart contracts, the MetaMask wallet, and the Sepolia test network to demonstrate blockchain-based transactions. By automating payment conditions and maintaining transparent transaction records, the system aims to reduce dependency on intermediaries and promote a more reliable freelancing environment.

The main objective of CHAIN TRUST is to provide a secure, transparent, and decentralized platform for managing freelance contracts and payments while improving trust between clients and freelancers.
